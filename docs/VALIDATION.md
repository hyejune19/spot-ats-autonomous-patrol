Nav2의 성공 판정은 `results/nav_ros_retry.json`의 액션 결과를 기준으로 한다. 목표 허용 오차는 생성된 Nav2 설정에서 확인한다. LLM의 첫 번째 계획과 Nav2 시험의 목적지는 같지만 이번 기록은 독립 시험이며, 자동으로 연속 실행한 증거로 주장하지 않는다. 공개 실행기는 `observe_ros.py --plan results/llm_plans.json`으로 제한된 단일 이동 계획을 입력할 수 있도록 구성했다. 이 추가 입력 경로의 전체 실행은 아직 별도로 검증하지 않았다.

## 영상 제작과 검증

외부 관찰 카메라와 RGB·깊이는 Isaac Sim에서 직접 기록한다. 물리 스텝은 0.002초, 정책 스텝은 0.02초이며 외부 영상은 시뮬레이션 0.1초 간격으로 저장한다. 추가 렌더 호출은 물리를 진행시키지 않는다. MP4는 H.264·yuv420p로 저장하고 GIF는 README에 직접 삽입한다.

LLM 애니메이션은 실제 응답 JSON의 단계별 설명이다. RGB·YOLO·깊이 합성 화면은 실제 센서 프레임에 실제 추론 결과와 깊이 색상 범례를 더한 화면이다. RViz 영상은 해당 프로그램 창만 촬영한다.

## 현재 개선 과제

- Nav2 시작 시 통신 지연이 있었으며 양쪽에 동일한 UDP 프로파일을 적용한 실행에서 활성화를 확인했다. 단일 원인을 확정하는 진단은 수행하지 않았다.
- 기초 ROS 어댑터의 카메라 TF는 body 기준 고정 프레임이다. ATS 관절에 따른 시선·광학 좌표계와의 일치는 후속 과제이다.
- 오도메트리 twist의 좌표계, IMU의 프레임·가속도 구성, 카메라 내부 파라미터는 실측 센서 수준의 검증이 추가로 필요하다.
- 형식 검증은 허용 task와 데이터 구조를 제한하지만 모든 계획의 의미적·물리적 타당성을 증명하지 않는다.
- 기존 외부 의존성에는 상용 배포 및 수정본 재배포 제약이 있다. 공개 저장소만으로 전체 환경을 재현할 수는 없다.
